## Coordinate and geometry contract

The SDK manifest declares **millimetres**, **+Y up**, **+Z forward**. The model's numeric vertex coordinates are in millimetres; generic glTF consumers normally assume metres and must apply the declared unit conversion when importing it outside this SDK. The nose-bridge centreline and model origin are both `(0, 0, 0)`. Both temples extend behind the front towards **-Z**. Left/right node labels denote the model's negative/positive X sides.

| Design measure | Value | Definition |
| --- | ---: | --- |
| Frame width | 140 mm | Maximum X extent including the two hinge blocks |
| Lens width | 52 mm | Each transparent lens contour's X extent |
| Lens height | 36 mm | Each transparent lens contour's Y extent |
| Bridge width | 16 mm | Minimum horizontal gap between the two lens contours |
| Temple length | 140 mm | Each hinge-to-tip polyline centreline, not a straight Z projection |
| Lens-centre spacing | 68 mm | Synthetic design parameter; not a user's PD |

The closed frame has bevelled rims, a curved bridge, two metallic hinge blocks, two full temples with downturned tips, and two thin transparent lenses. Material names distinguish `frame_navy_acetate`, `frame_hinge_metal` and `lens_clear`. There are 9 mesh primitives and **4,096 triangles**; no texture, external buffer, compression decoder or glTF extension is required. Geometry is explicitly triangulated with finite positions, outward normals and no zero-area triangles.

Overall bounds in millimetres: minimum `[-70,-23,-137.834439]`, maximum `[70,19,2.5]`. The manifest anchors are also embedded as named empty glTF nodes for inspection.
